## 🚀 What I'm working with right now

My day-to-day is centered on **functional programming with Clojure**, **event-driven architectures** and **cloud data pipelines**. I build backend services that process streams of events in real time, persist data in distributed and relational databases, and feed analytics workloads on AWS.

- **Functional backend:** Clojure and ClojureScript for services and front-end code.
- **Streaming:** Kafka and Kafka Streams for event-driven processing.
- **Persistence:** Cassandra for high-volume distributed data and PostgreSQL for relational data.
-  **Data & Cloud:** S3, Athena, Glue and Lambda for storage, cataloging, querying and serverless processing.
